Privacy

Air Travel Desk sets no cookies, runs no analytics or trackers, has no accounts, and stores nothing in your browser.

What this page loads

The page loads only files hosted on this site: HTML, CSS, JavaScript, icons, and the status JSON file. It does not load third-party scripts, fonts, or embeds.

Hosting logs

This site is hosted on GitHub Pages, which keeps standard server logs that may include your IP address and request metadata. See GitHub's Privacy Statement for details.

Flight and weather data

Airport status and weather alert data comes from FAA NAS status and National Weather Service alerts. An automated job fetches those public feeds every few minutes and writes a static file to this site, so no viewer data is ever sent to the FAA or the National Weather Service when you load this page.

External links

The links to YouTube and Downtime Credit go to other websites that operate under their own privacy policies.

Contact

If you have a question or privacy concern, please open an issue on GitHub.
